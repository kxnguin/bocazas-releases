# Bocazas

Dictado por voz para Windows, de [Mairoa](https://mairoa.com). Hablas y el texto aparece donde estés escribiendo.

Este repositorio solo guarda los instaladores y las actualizaciones. El código no está aquí.

## Instalar

1. Descarga `Bocazas_<versión>_x64-setup.exe` de la [última versión](https://github.com/kxnguin/bocazas-releases/releases/latest).
2. Ábrelo. Si Windows muestra «Windows protegió su PC», pulsa **Más información** y luego **Ejecutar de todas formas**. El aviso sale porque el instalador aún no lleva certificado de empresa.

Bocazas se actualiza sola desde aquí. Cada actualización va firmada, y la app rechaza cualquier descarga que no lleve la firma de Mairoa.
